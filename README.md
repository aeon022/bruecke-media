# bruecke-media

Öffentliche Bild-URLs für die Social-Media-Posts der Brücke (Instagram lädt Bilder per https).
Quelle der Wahrheit ist das OneDrive (`…/Social Media/…/Final/`); hierher wird nur kopiert, was gepostet wird.

- `einzelevents/feed|story/` — Einzelevents, 1080×1350 (Feed) bzw. 1080×1920 (Story)
- `wochen/feed|story/` — Wochenübersichten (`2026_KW43_Seite-01-von-01.png`)
- `feed/` — Altlast (ABBA 4 YOU), kann nach der Veröffentlichung entfernt werden

Nichts Privates ablegen — das Repo ist öffentlich.
